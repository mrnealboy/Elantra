DTC Information And Inspection: DTC Detecting Condition

Trouble shooting Condition Possible cause
Main action
  • Monitor the calibration state of the sensor
  1. Longitudinal G sensor is not calibrated
  2. Faulty G sensor
  3. Controller power supply failure
  4. Faulty ESP (ESC)
Threshold value
  • A failure is detected when the received serial number from sensor and stored sensor serial number in EEPROM of ECS does not match for 3 times.
  • The calibration of the corresponding sensor has not been executed.
  • When sensor replacement is detected
Diagnosis time
  • 100 milliseconds
MIL
  • ESP (ESC) warning lamp is activated
Reset condition
  • When the normal state is confirmed after ignition switch turned OFF and back ON.
