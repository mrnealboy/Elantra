DTC Information And Inspection: DTC Detecting Condition

Trouble Shooting Condition Possible Cause
Main Action
  • Monitor the Gateway signals
  1. Poor contact of connector
  2. Poor connection of connector
  3. Open/short in wire harness
  4. Gateway module (ICU Junction block)
Prerequisite Condition
  • Turn on the ignition switch and start the engine
Threshold Value
  • An abnormal Gateway signal was receive
Diagnosis Time
  • 2 sec
