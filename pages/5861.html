Repair Procedures: Installation: Notes

The type can replace the wheel side joint boot

NOTE:
  • When assembling, be careful not to let dust and foreign substances enter.
  • Driveshaft joints require special grease, so do not add any other type of grease.
  • Boot bands must use the new one.
  1. Install the new boot in the direction of the arrow.
  2. Apply the grease specified inside the boot.
    NOTE:
    • Use the grease provided with the joint/boot kit.
    • Apply about 50 - 60% grease inside the boot.
    • Driveshaft joints require special grease, so do not add any other type of grease.
  3. Install the wheel side boot into the housing .
  4. Install the large diameter boot band using SST (0K495-C5000).

    Clearance :  2.0 mm or less.

  5. Install the small diameter boot band using SST (0K495-C5000).

    Clearance :  2.0 mm or less.

  6. Install the dynamic damper.[If equipped] 

    (Refer to "DYNAMIC DAMPER ")

  7. Install the transaxle side joint.

    (Refer to "JOINT ASSEMBLY (TRANSAXLE SIDE) ")

  8. Install the front drive shaft.

    (Refer to "FRONT DRIVESHAFT ")
