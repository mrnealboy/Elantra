Smartkey Lamp Warning

  1. If terminal state is ACC or IGN and vehicle speed is less than 3 km/h, a periodic search (every 3s) is done at the interior of the vehicle to check that the valid fob is still in the in the vehicle.
  2. If no valid Fob is found a Warning is started, but if a valid Fob is found then no action is started.
