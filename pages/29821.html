Wireless Smartphone Projection Information (25-GI-013H)

WIRELESS SMARTPHONE PROJECTION INFORMATION

WIRELESS SMARTPHONE PROJECTION INFORMATION

TECHNICAL SERVICE BULLETIN

Reference Number(s): 25-GI-013H, Date of Issue:  June 01, 2025
HYUNDAI: All Models
GROUP: GENERAL INFORMATION

DESCRIPTION

This bulletin provides information on the connection process of the Apple CarPlay and Android Auto wireless projection between the head unit and connected smartphone.

Applicable Vehicles: 

  • 2020-2023MY models equipped with DAUDIO 2.0 VALUE (software versions includes standard identifier "USA.D2V")
  • 2024-2025MY models equipped with ccNC Navigation (software versions include standard identifier "USA.ccNC")

DAUDIO 2.0 VALUE OR CCNC NAVIGATION IDENTIFICATION

Model/MY Figure Remarks
2020-2023 models equipped with DAUDIO 2.0 VALUE
DAUDIO 2.0 VALUE and ccNC Navigation are the only Hyundai head unit types that support Wireless Phone Projection
2024-2025 models equipped with ccNC Navigation
NOTE: Refer to standard identifiers 'USA.D2V  .' and 'USA.ccNC  ' in the software version to determine if vehicle is equipped with DAUDIO 2.0 value OR ccNc Navigation

WARRANTY INFORMATION

NOTE:
  1. Normal warranty applies.

STANDARD CONNECTION PROCESS

  1. When the ignition is ON  , the smartphone pairs with the head unit via Bluetooth to exchange network credentials (SSID, password, channel, etc.).
  2. The smartphone connects to the head unit's internal Wi-Fi using the shared credentials.
  3. Screen mirroring begins with Apple CarPlay or Android Auto functionality.

    Information 

    This process is based on Apple and Google's current wireless projection functionalities.

COMMON USE SCENARIOS

  1. If the smartphone is:
    • Connected to a home or other Wi-FI network  , it will NOT  switch automatically to the vehicle's Wi-FI.
    • Hosting a hotspot  , transition to the head unit's Wi-Fi may be delayed or blocked.
    • Previously connected to another vehicle via Bluetooth  , switching may require manually disconnecting the prior connection.
  2. To expedite the connection, access Device Connections  in the head unit's settings and manually select the desired device.
