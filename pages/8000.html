DTC Description

U010900 is set when no data is received from the Fuel Pump Control Module (FPCM).

(CAN Time Out: Communication among control modules is unavailable_power is not properly supplied to the control modules_poor contact of the main line - refer to "HIGH SPEED CAN COMMUNICATION ")
