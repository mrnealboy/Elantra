Steering Sensor Initialization

  1. Align all wheels in a straight line.
    1. Make sure all wheels are aligned in a straight line.
    2. Align the steering wheel with the wheels.
  2. Connect GDS to Data Link Connector (DLC).
  3. Select "ECU Specification Information" on the menu.
  4. Conduct "Steering Angle Sensor Initialization".
  5. Check if the steering angle sensor value on the "Current Data" is normal and go to "Verification of Vehicle Repair".
  6. Test-drive the vehicle (turn 1 time to the left and 1 time to the right) and check if the 0-point setting has been properly conducted.
