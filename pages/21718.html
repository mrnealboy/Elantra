DTC Description

WARNING: This page is about a different variant/trim than selected.

A DTC sets when either of the "Main" lines attached to CAN High line and CAN Low line suffers poor contact. Communication will work properly.

A transmitter control module will set this DTC when a sensor signal or state signal is abnormal. On the other hand, a receiver control module will set this when a signal is out of specification or when data are not in line with the predetermined checksum.
