DTC Information And Inspection: DTC Detecting Condition

WARNING: This page is about a different variant/trim than selected.
Item Detecting Condition Possible Cause
DTC Strategy Case 1
  • TMM control duty monitoring
  1. Poor connector connection
  2. Faulty integrated flow control valve (ITM) circuit
  3. Faulty integrated flow control valve (ITM)
Case 2
  • TMM feedback current monitoring
Case 3
  • Monitoring target follow-up
Enable Condition Case 1
  • No P26A500, P26A600, P26A700, U063F00 related DTC
  • ITM position is between -5° and 335°
  • Difference between ITM target position and actual position is less than 1°
Case 2
  • No P26A500, P26A600, P26A700, U063F00 related DTC
  • No trouble related to followable fault or excessive duty fault
  • Ignition "ON"
Case 3
  • ITM position is between 8° and 320°
  • Difference between ITM target position and actual position is less than 4°
  • ITM motor duty is more than 0%
Threshold Value Case 1
  • ITM motor duty is more than 40%s
Case 2
  • ITM feedback current of more than 6.3A
Case 3
  • If the difference between ITM target position and actual position is more than 8°
Diagnostic Time Case 1
  • 5 seconds
Case 2
  • 3 seconds
Case 3
  • 5 times every 4 seconds or once every 20 seconds
MIL ON Condition
  • 2 driving cycles
