Repair Procedures: Inspection

WARNING: This page is about a different variant/trim than selected.
  1. The DCT system can be more quickly diagnosed for troubles by using the vehicle diagnostic system (diagnostic tool). (Refer to DUAL CLUTCH TRANSMISSION (1.6L) DTC information)

    diagnostic tool provides the following information. 

    1. Self diagnosis: Inspects and displays diagnostic trouble code (DTC)
    2. CAN signals: Checks the system input/output value status
    3. Forced operation: Checks the system operating status
    4. Additional function: Controls system options, zero point adjustment and other functions
