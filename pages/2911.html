BSD EOL Coding

  1. How to perform 'BSD EOL Coding'

    * Prerequisite condition: Test after stabilizing the vehicle (stabilize the suspension).

    Place the device on the level ground. Secure sufficient space around it (over "1"m).

    Make sure there is no moving object around the vehicle during the test.

    1. Align the wheels and steering wheel straight in line with the vehicle position.
      • Check the bumper for its installation state and surface condition (sticker, mud).
    2. Make sure that the BSW Coding device is installed perpendicularly to the level ground.
    3. Turn on the ignition switch.
    4. Connect a GDS to Data Link Connector (DLC).
    5. Select "Inspection/Test Mode" on the GDS menu.
    6. Perform "BSD EOL CODING ."
    7. Confirm a "Setting Completed" notification.
      1. If the coding is interrupted halfway, repeat the procedure from Step 1). (try 5 times)
      2. If you still fail after repeating 7-2) 5 times.
        • Check the bumper for its installation state (surface condition, bumper).
        • Remove the bumper and check for the bracket installation.
          • Check the location of the bracket (Refer to the guidelines).
          • Check radar installation: loosened screws (3 points), foreign substance between screws.
        • If there is a problem, fix it. If none, re-assemble the bumper and repeat the procedure from Step  1). (try for 5 times)
      3. Replace it with a new sensor if you still fail after repeating 7-3) 5 times.
