DTC Description

P007100 will set when the actual Ambient Air Temperature Sensor (AATS) reading, supplied via CAN, is different (greater than 77°F (25°C)) than the ECU calculated value utilizing the combination of two sensors, Intake Air Temp Sensor (IAT) Oil Temperature Sensor (OTS) and/or Engine Coolant Temperature (ECT) Sensor.
