DTC Description

B165C00 is set when there is no learning procedure after placing the new IAU*, although it is installed and connected.

NOTE: This DTC is not set when you replace the component with the "Learnt IAU*" from the other vehicle. However, the digital key system will not work since there is no learning procedure between the car and the IBU*.
