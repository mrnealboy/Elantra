DTC Description

If it is impossible to communicate through internal or external CAN line over 2 sec, Engine Electronic Control Unit (ECU) sets DTC U000100.

(CAN BUS OFF: Communication is unavailable_an open/short in the main line_a short in the branch - refer to "HIGH SPEED CAN COMMUNICATION ")
