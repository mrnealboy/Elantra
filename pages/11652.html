Monitor Scantool Data

  1. Connect GDS to Data Link Connector (DLC).
  2. Ignition switch ON and the Engine OFF, select "Diagnostic Trouble Codes (DTC)" mode.
  3. Monitor diagnostic trouble code and present of trouble code.
  4. Using the GDS, clear the DTC.
  5. The seats must be taken by adults.
  6. Monitor the "PODS Occupant Classification" Of the "Current Data" parameter on the GDS.
