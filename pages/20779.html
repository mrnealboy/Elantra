Repair Procedures: Inspection: Piston

WARNING: This page is about a different variant/trim than selected.
  1. Clean piston.
    1. Using a gasket scraper, remove the carbon from the piston top.
    2. Using a groove cleaning tool or broken ring, clean the piston ring grooves.
    3. Using solvent and a brush, thoroughly clean the piston.
      NOTE:
      • Do not use a wire brush.
  2. Check the piston-to-cylinder clearance by calculating the difference between the cylinder bore inner diameter and the piston outer diameter.

    Piston-to-cylinder clearance: 

    0.02 - 0.04 mm (0.0008 - 0.0016 in.)

    1. Using a cylinder bore gauge, measure the cylinder bore diameter at position in the thrust and axial direction.

      Cylinder bore diameter: 

      81.00 - 81.03 mm (3.1890 - 3.1902 in.)

      Courtesy of HYUNDAI MOTOR AMERICA

      Information 

      • Measuring direction: Axial direction, Thrust direction
      • Measuring height: From the top of the cylinder block 30 mm (1.1811 in.)/60 mm (2.3622 in.)/90 mm (3.5433 in.)
    2. Measure the piston outside diameter at 35 mm (1.3780 in) from top land of the piston.

      Piston outside diameter: 

      80.97 - 81.00 mm (3.1878 - 3.1890 in.)

      Courtesy of HYUNDAI MOTOR AMERICA
  3. Select the piston matching with cylinder bore class.

    Piston-to-cylinder clearance: 

    0.02 - 0.04 mm (0.0008 - 0.0016 in.)

    1. Check the cylinder bore size code on the cylinder block side surface.
      CYLINDER BORE INNER DIAMETER SPECIFICATION

      Size Code Cylinder Bore Inner Diameter
      A 81.00 - 81.010 mm (3.1890 - 3.1894 in.)
      B 81.010 - 81.020 mm (3.1894 - 3.1898 in.)
      C 81.020 - 81.030 mm (3.1898 - 3.1902 in.)
      Courtesy of HYUNDAI MOTOR AMERICA
    2. Check the piston size mark on the piston top face.
      Courtesy of HYUNDAI MOTOR AMERICA
      PISTON OUTER DIAMETER SPECIFICATION

      Size Code Piston Outer Diameter
      A 80.965 - 80.975 mm (3.1876 - 3.1880 in.)
      B 80.975 - 80.985 mm (3.1880 - 3.1884 in.)
      C 80.985 - 80.995 mm (3.1884 - 3.1888 in.)
