Repair Procedures: Installation

  1. Install the wiper motor and linkage assembly and then connect the wiper motor connector.

    Tightening torque:  7.0 - 11.0 Nm (0.7 - 1.1 kgf.m, 5.0 - 7.9 lbf.ft)

  2. Install the crank arm.

    Tightening torque:  14.7 - 19.6 Nm (1.5 - 2.0 kgf.m, 10.8 - 14.5 lbf.ft)

  3. Install the cowl top cover.
  4. Install the windshield wiper arm and blade.

    Tightening torque:  23.0 - 27.0 Nm (2.3 - 2.7 kgf.m, 16.6 - 19.5 lbf.ft)

    NOTE:
    • The windshield wiper motor must be cycled to make sure that it is in the park position.
    • If necessary, adjust the wiper arm and blade.
  5. Install the wiper arm and blade to the specified position.
