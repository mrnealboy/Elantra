DTC Information And Inspection: DTC Detecting Condition

Trouble shooting Condition Possible cause
Main action
  • Internal monitoring
  1. Poor contact of connector
  2. Controller power supply failure
  3. Faulty ESP (ESC)
Threshold value
  • When a hardware error in the ESP (ESC) module is detected.

    * Hardware error:

    1. RAM/ROM's Bit error Monitoring
    2. Stack over/under flow Monitoring
    3. Main MCU & ASIC Communication Monitoring
    4. Interrupt/Timer/CPU Calculation Monitoring
    5. MCU Self test monitoring
Diagnosis time
  • Immediately
MIL
  • ABS/ESP (ESC)/EBD warning lamps are activated
Reset condition
  • When the normal state is confirmed after ignition switch turned OFF and back ON.
