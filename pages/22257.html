Repair Procedures: Installation

WARNING: This page is about a different variant/trim than selected.
NOTE:
  • Note that internal damage may occur when the component is dropped. In this case, use it after inspecting.
  • Note that install the variable force solenoid (VFS) as below.
  1. After replacing the variable force solenoid valve (VFS) O-ring (A), apply the engine oil on the new O-ring.
    Courtesy of HYUNDAI MOTOR AMERICA
  2. Tighten the variable force solenoid valve (VFS) all the way to the timing chain cover mounting surface, and then temporary tighten the bolts.
  3. Install the variable force solenoid with the specified torques.
  1. Install in the reverse order of removal.
