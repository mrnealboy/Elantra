DTC Description

B163700 is set when initially the Driver Seat Motor's Position Information* is not set or when the set position information of Driver Seat Motor was cleared.

When this DTC is set, perform the "Seat Limit Position Setting" procedure in the "Vehicle S/W Management" with GDS.
