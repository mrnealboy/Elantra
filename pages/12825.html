DTC Information And Inspection: DTC Detecting Condition

WARNING: This page is about a different variant/trim than selected.
Item Detecting Condition Possible Cause
DTC Strategy Case 1
  • Engine speed is above the target while ISC torque is around the minimum
  1. Poor connector connection
  2. Intake system air leakage
  3. Exhaust system air leakage
  4. Binding throttle valve
Case 2
  • Fuel cut-off during stand-still and idle condition
Enable Condition
  • Vehicle speed = 0 mph
  • ECT greater than 50°C (122°F)
  • Intake air temperature greater than -10.5°C (13.1°F)
  • Acceleration pedal = 0%
  • BARO greater than 74.5 kpa (0.74 bar/10.80 psi)
Threshold Value Case 1
  • Difference between the target engine speed and the actual engine speed is more than 200 RPM
  • Difference between the maximum idling torque and the actual idling torque is less than 20Nm
Case 2
  • More than 3 times fuel cut-off detections
Diagnostic Time Case 1
  • 8 seconds
Case 2
  • 15 seconds
MIL ON Condition
  • 2 Driving Cycles
