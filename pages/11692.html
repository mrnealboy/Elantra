Occupant Classification System (OCS)

  1. Install the occupant classification sensor unit in the passenger seat track assembly.
  2. Connect the occupant classification sensor unit connector.
  3. Install the passenger seat cushion assembly. (Refer to Body (Interior and Exterior) - "FRONT SEAT CUSHION COVER ")
  4. Install the passenger's side front seat assembly. (Refer to Body (Interior and Exterior) - "FRONT SEAT ASSEMBLY ")
  5. Reconnect the battery negative (-) terminal.
  6. After installing the OCS, confirm proper system operation.
    NOTE:
    • Turn the ignition switch ON the SRS indicator should be turned on for about 6 seconds and then go off.
    • Telltale lamp will turn on for 4 seconds and be turned off for 3 seconds. After the 7 seconds, it shall remain off if the OCS does not require suppression and the passenger airbag is enabled.
    • Be sure to perform OCS reset with diagnostic tool after replacing OCS equipped seat cushion.
    CAUTION:
    • After initializing the OCS sensor unit, erase DTC regarding the SRSCM and the OCS sensor unit.
    DTC DESCRIPTIONS

    DTC Code Code Name Description
    B1697 (87) ACU Communication Error
    1. ACU message cannot be received
    B1603 (88) CAN BUS OFF
    1. Vehicle CAN BUS bad reception
    P1680 (87) VS Communication Fault
    1. Vehicle speed message cannot be received
    P1681 (81) VS Message Failure
    1. Receive vehicle speed error signal
    B1111 (17) Ignition Voltage High
    1. High voltage condition (18.1V over)
    B1112 (16) Ignition Voltage Low
    1. Low voltage condition (6.7V under)
    B1763 (00) OCS ECU Defect ECU internal element failure or S/W failure
    B1496 (54) OCS Not Calibrated
    1. Sheet factory zero adjustment process missing
    B1499 (07) ALR Defect
    1. ALR broken
