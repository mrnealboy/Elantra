DTC Information And Inspection: DTC Detecting Condition

WARNING: This page is about a different variant/trim than selected.
Trouble Shooting Condition Possible Cause
DTC Strategy
  • Monitoring speed difference between input speed sensor and calculated input speed based on wheel speed sensor
  1. Faulty DCT
  2. Fault 2nd gear ratio
Enable Condition
  • No failure on input speed sensor2, wheel speed sensor and CAN 1 during driving in 2nd gear
Threshold Value
  • Input speed sensor2 value - wheel speed sensor value * gear ratio * tire radius greater than MAX (400, 0.15 * wheel speed sensor value * gear ratio * tire radius)
Detecting Time
  • 5 times per second
Fail Safe
  • Drive at Odd gear (1/3/5/7)
