DTC Description

The Supplemental Restraint System Control Module (SRSCM) sets DTC B110200 and turns warning light on if voltage below threshold value is detected for more than 4 sec. (If voltage within threshold value is detected When the SRSCM returns to normal condition. SRSCM regards DTC as being cleared and turns warning light off).
