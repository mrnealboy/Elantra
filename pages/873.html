Component Function: Cluster

Courtesy of HYUNDAI MOTOR AMERICA

The cluster module controls a variety of functions including MIL, trip computer, cluster text warning display, user option (USM, User setting MODE) setting, and sounds by receiving information through CAN communication lines. It also functions the variant coding, which synchronizes the cluster settings with the vehicle's system specifications registered by GDS.
