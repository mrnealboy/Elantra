DTC Description

WARNING: This page is about a different variant/trim than selected.

The PCM monitors the range of the analog input signal from knock sensor to check sensor failure that is short circuit or open circuit. If the difference between knock signal and noise level is smaller than the threshold during defined time period, the DTC P032600 is set. P032600 will also set if the noise value exceeds the minimum or maximum thresholds.
