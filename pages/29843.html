GOOGLE MAPS DELAY WHILE USING APPLE CARPLAY SERVICE

TECHNICAL SERVICE BULLETIN

Reference Number(s): 23-BE-007H, Date of Issue:  July 25, 2023
HYUNDAI: 2017-2021 Ioniq Electric (AE EV); 2017-2022 Ioniq Hybrid (AE HEV); 2018-2022 Ioniq Plug-in (AE PHEV); 2020-2023 Sonata (DN8/DN8a); 2020-2023 Sonata Hybrid (DN8 HEV); 2018-2023 Kona (OS); 2022-2023 Kona N (OS N); 2019-2023 Kona Electric (OS EV); 2020-2022 Palisade (LX2); 2019-2022 Veloster N (JSN); 2021-2023 Elantra (CN7/CN7a); 2021-2023 Elantra N (CN7 N); 2021-2023 Elantra Hybrid (CN7 HEV); 2019-2023 Santa Fe (TMa) (VIN starts with '5NM'); 2021-2022 Santa Fe Hybrid (TM HEV) (VIN starts with 'KM8'); 2023 Santa Fe Hybrid (TMa HEV) (VIN starts with '5NM'); 2022-2023 Santa Fe Plug-in (TM PHEV); 2020-2022 Venue (QX); 2020 - 2022 Venue (QX)
GROUP: BODY ELECTRICAL

SERVICE INFORMATION

IMPORTANT: This bulletin is informational and intended for dealers to assist customers with their Apply CarPlay software upon customer request. The procedure outlined within this bulletin is not covered by Hyundai warranty and customer expense may apply.

DESCRIPTION

This Service Information bulletin provides information on how to update the Apple Carplay software from Hyundai's Navigation Updates information. The current version of Google Maps has 10 times the data transmission compared to the previous version. As a countermeasure, an update with a frame skip logic has been added to resolve the data congestion with Google Maps.

Applicable Vehicles with Apple CarPlay: 

  • 2017-2021 Ioniq Electric (AE EV)
  • 2017-2022MY Ioniq Hybrid (AE HEV)
  • 2018-2022MY Ioniq Plug-in (AE PHEV)
  • 2020-2023MY Sonata (DN8/DN8a)
  • 2020-2023MY Sonata Hybrid (DN8 HEV)
  • 2018-2023MY Kona (OS)
  • 2022-2023MY Kona N (OS N)
  • 2019-2023MY Kona Electric (OS EV)
  • 2020-2022MY Palisade (LX2)
  • 2019-2022MY Veloster N (JSN)
  • 2021-2023MY Elantra (CN7/CN7a)
  • 2021-2023MY Elantra N (CN7 N)
  • 2021-2023MY Elantra Hybrid (CN7 HEV)
  • 2019-2023MY Santa Fe (TMa) (VIN starts with '5NM')
  • 2021-2022MY Santa Fe Hybrid (TM HEV) (VIN starts with 'KM8')
  • 2023MY Santa Fe Hybrid (TMa HEV) (VIN starts with '5NM')
  • 2022-2023MY Santa Fe Plug-in (TM PHEV)
  • 2020-2022MY Venue (QX)Certain 2020 - 2022MY Venue (QX)

Circulate To: General Manager, Service Manager, Sales Manager, Parts Manager, Warranty Manager, Service Advisors, Technicians, Body Shop Manager, Fleet Repair

SERVICE INFORMATION

  1. Access Hyundai's Navigation Updates page to update the Apple CarPlay app by opening the link below:

    https://update.hyundai.com/US/EN/Main 

    Information 

    Instead of submitting a Warranty claim, the update should resolve the issues with the Apple CarPlay app.
  2. Follow the prompts to download update software and select the applicable vehicle.

    Download and store the update onto a USB drive.

    Insert the USB drive into the vehicle to perform a software update.
