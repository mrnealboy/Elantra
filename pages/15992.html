DTC Setting Condition

Trouble Shooting Condition Possible Cause
Main Action
  • Monitor the CAN messages
  1. Open/short in P-CAN communication circuit
  2. Open/short in C-CAN communication circuit
  3. Faulty EMS system
  4. Faulty gateway (CGW) system
  5. A radar for a hybrid vehicle is mounted
Prerequisite Condition
  • Battery Voltage is between 9V and 16V
  • Ignition has been on for over 2 seconds (Time Delay)
  • CAN communication lines are normal
Threshold Value
  • When the FCA/SCC fails to receive the EMS messages
  • When the FCA/SCC receives the "EMS message reception error" signal from the gateway (CGW)
Diagnostic Time
  • 0.5 seconds
MIL
  • FCA/SCC operation cancelled/inhibited
  • FCA/SCC warning lamp ON
