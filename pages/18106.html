DTC Information And Inspection: DTC Detecting Condition

WARNING: This page is about a different variant/trim than selected.
Item Detecting Condition Possible Cause
DTC Strategy
  • Difference between camshaft edge actual and reference position (out of range) with CVVT in full retard position
  1. Poor connector connection
  2. Faulty valve timing
  3. Loosened CKPS
  4. Timing misalignment
Enable Condition
  • Camshaft position adaptation value is valid
Threshold Value
  • Camshaft position adaptation is lower than -15°
  • Camshaft position adaptation is higher than 15°
Diagnostic Time
  • 80 revolution
MIL ON Condition
  • 2 driving cycles
