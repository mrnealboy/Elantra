DTC Setting Condition

Trouble Shooting Condition Possible Cause
Main Action
  • Monitor the FATC*'s CAN message reception
  1. Oepn in CAN high/low line
  2. FATC*
Prerequisite Condition
  • Turn the ignition switch ON
Threshold Value
  • The ADAS-PRK* unit has not received a message from the FATC*
Diagnosis Time
  • No CAN message has been transmitted for 5 sec
DTC Clearing
  • -
NOTE: ADAS-PRK*: "Advanced driver assistance system - Parking"
FATC*: "FRONT Automatic Temperature Control"
