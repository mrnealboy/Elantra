DTC Description

WARNING: This page is about a different variant/trim than selected.

If the lambda controller reaches the maximum or minimum threshold, then feedback control is no longer possible and emissions will be increased. The PCM sets DTC P218700 if no proportional post catalyst fuel trim adaptation occurs for a defined time after the lambda controller has reached its maximum threshold at idle.
