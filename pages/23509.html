Repair Procedures: Reassembly

  1. To reassembly, reverse the disassembly procedure.
  2. Using SST (09546-3X100), install the lock nut.
    NOTE:
    • Do not reuse the self locking nut.

    Tightening torque:  19.6 - 24.5 N.m (2.0 - 2.5 kgf.m, 14.5 - 18.1 lb-ft)

    Courtesy of HYUNDAI MOTOR AMERICA
  3. Install the insulator cap (A).
    Courtesy of HYUNDAI MOTOR AMERICA
