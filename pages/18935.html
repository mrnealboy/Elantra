DTC Information And Inspection: DTC Detecting Condition

WARNING: This page is about a different variant/trim than selected.
Trouble shooting Prerequisite condition Possible Cause
Main action
  • Monitor the gear ratio
  1. IVT (Infinitely Variable Transmission)
  2. PCM
Prerequisite condition
  • Battery voltage: 10V or more
  • Engine RPM: 350 RPM or more
  • Shift lever switch: "D" or "Sports" (Forward gear)
  • Shift lever oil temperature: -10°C or more
  • Solenoid "ON"
  • No CAN error
  • Target speed ratio: 0.4 or less
  • Vehicle speed: 20 km/h or more
Threshold Value
  • 0.5 or more difference between the target speed ratio and the current speed ratio
Detecting Time
  • 5 sec
MIL ON Condition
  • 2 driving cycles
Fail safe
  • Solenoid power "OFF", Learning should not be performed, Lower engine torque, Control Cooling FAN
