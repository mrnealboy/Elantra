Repair Procedures: Installation

  1. Install the side repeater lamp.
  2. Install the front housing cover.
    CAUTION:
    • When front housing cover installing, install the folded area first and then the far area.
    • Pushing the around of front housing cover with both hands and then make sure that it is completely installed.
  3. Install the scalp (cover).
    CAUTION:
    • Install the scalp in the vertical direction that the inner fixing hook is not damaged.
    • When scalp installing, install the folded area first and then the far area.
    • Pushing the around of scalp with both hands and then make sure that it is completely installed.
  4. Connect mirror wire connectors.
  5. Install the door mirror assembly.
  6. Connect (-) battery terminal then check if door mirror lamp works normally.
