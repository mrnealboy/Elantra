DTC Setting Condition

Trouble Shooting Condition Possible Cause
Main Action
  • Monitor the output current
  1. Open/Poor Connection in Power Circuit
  2. Short-to-Ground in Power Circuit
  3. Open/Poor Connection in Ground Circuit
Prerequisite Condition
  • Power Voltage: Between 9V and 16V
  • Check the antenna state only under 'DTC Read' condition
Threshold Value
  • An open in the antenna circuit
Diagnostic Time
  • 300 ms
  • DTC regarding the antenna in question will appear when DTC Read command was received and all 4 LF antennas are in operation
DTC Clearing
  • DTC related to the antenna is set only when the problem is present. Thus, if the antenna works properly, DTCs will not be set
NOTE: Interior Antenna #2*: "SMART KEY ANTENNA (INTERIOR #1)"
