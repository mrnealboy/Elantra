DTC Description

In order to run the airbag system normally, check whether incorrect vehicle specifications appear while performing "ACU Variant Coding". This DTC is set up if Supplemental Restraint System Control Module (SRSCM) variant code doesn't match with the entering variant code at performing "ACU Variant Coding" procedure.
