A/C REFRIGERANT RECOVERY & CHARGING ONLY WARRANTY CLAIM GUIDELINES

A/C REFRIGERANT RECOVERY & CHARGING ONLY WARRANTY CLAIM GUIDELINES

SERVICE CAMPAIGN BULLETIN

Reference Number(s): 24-HA-002H, Date of Issue:  November 01, 2024
HYUNDAI: All Models
GROUP: HVAC
Superceded Bulletin(s): 14-HA-002, Date of Issue:  November 01, 2024

REVISION HISTORY

This TSB supersedes TSB 14-HA-002 to update Warranty information, including a new Op Code for R-1234YF and additional notes. 

DESCRIPTION

This bulletin provides warranty claim information for service repairs requiring A/C refrigerant recovery and charging.

The non-part code "ACGAS00000" MUST  be used for the causal part whenever Op Code 09760A00 is claimed and the following apply:

  • NO  cause was determined.
  • NO  parts were replaced (other than refrigerant for charging).
  • ONLY  A/C refrigerant recovery and charging procedures were done.

If the actual cause can be determined, then the applicable causal part number should be used.

Applicable Vehicles: 

  • All models
NOTE: To avoid any potential damage to IONIQ vehicles, IONIQ repairs can only be performed at IONIQ certified dealers.

WARRANTY INFORMATION: NO CAUSAL PART FOUND

WARRANTY INFORMATION

Model Op. Code Operation Op. Time Causal Part Nature Code Cause Code
All 09760A00 A/C Refrigerant Recovery & Charging 0.5 M/H ACGAS00000 (See NOTE 2)
09760AA1 A/C Refrigerant Recovery & Charging (R-1234YF) 0.3 M/H
NOTE:
  1. Warranty coverage for Op Code 09760A00 = 12 months/unlimited mileage.
  2. Use the applicable Nature and Cause Codes according to the results of vehicle diagnosis.
  3. Claim both Op Codes for vehicles equipped with R-1234YF HVAC systems.

WARRANTY INFORMATION: CAUSE DETERMINED

WARRANTY INFORMATION

All 09760A00 A/C Refrigerant Recovery & Charging 0.5 M/H Use Applicable Causal Part (See NOTE 3)
09760AA1 A/C Refrigerant Recovery & Charging (R-1234YF) 0.3 M/H
NOTE:
  1. Do NOT  use "ACGAS00000" as Causal Part if parts were replaced for repair. Use the applicable causal part number.
  2. Warranty coverage for Op Code 09760A00 = 12 months/unlimited mileage.
  3. Use the applicable Nature and Cause Codes according to the results of vehicle diagnosis.
  4. Claim both Op Codes for vehicles equipped with R-1234YF HVAC systems.
