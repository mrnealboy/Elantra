DTC Information And Inspection: DTC Detecting Condition

WARNING: This page is about a different variant/trim than selected.
Item Detecting Condition Possible Cause
DTC Strategy
  • Check A/C control module signal abnormality
  1. Poor connection
  2. Open or short in AAT (Ambient air temperature) sensor circuit
  3. Faulty AAT sensor
Enable Condition
  • Ignition "ON"
Threshold Value
  • If an error message is received from the A/C control module
Diagnostic Time
  • 5 seconds
MIL ON Condition
  • 2 driving cycles
