DTC Data Analysis

  1. Plug GDS to Data Link Connector (DLC).
  2. Diagnose ESP (ESC) and select the "Front Left Wheel Speed Sensor" parameter in the "Current Data" menu of GDS.
  3. Monitor if the value changes according to vehicle speed.

    Specification:  Vary by vehicle speed
