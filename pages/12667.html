DTC Information And Inspection: DTC Detecting Condition

WARNING: This page is about a different variant/trim than selected.
Item Detecting Condition Possible Cause
DTC Strategy Case 1
  • TPS adaptation Lower position check
  1. Poor connector connection
  2. Learning failure
  3. Faulty ETC motor
Case 2
  • TPS adaptation error low return spring check
Case 3
  • TPS adaptation upper position check
Case 4
  • TPS adaptation error upper return spring check
Case 5
  • TPS start check error in spring check
Case 6
  • TPS start check error in limp-home-check
Enable Condition Case 1
  • During TPS adaptation
  • TPS setpoint is equal 11.9%
Case 2
  • During TPS adaptation
Case 3
  • During TPS adaptation
  • TPS setpoint is equal 29%
Case 4
  • During TPS adaptation
Case 5
  • During TPS start check
  • TPS setpoint is equal 24.2%
Case 6
  • During TPS start check
  • No engine start condition
Threshold Value Case 1
  • Throttle position for the lower return spring check is not reached within a limit maximum time (Difference between throttle position and setpoint is higher than 0.48%)
Case 2
  • When ETC power stage is off, Throttle can not return by spring power in the limp-home position within a limit maximum time (Difference between Throttle position and adapted voltage in limphome position is higher than 0.18V)
Case 3
  • Throttle position for the upper return spring check is not reached within a limit maximum time (Difference between throttle position and setpoint is higher than 0.48%)
Case 4
  • When ETC power stage is off, Throttle cannot return by spring power in the limp-home position within a limit maximum time (Difference between Throttle position and adapted voltage in limp home position is higher than 0.18V)
Case 5
  • Throttle flap cannot reach the setpoint within the hysteresis within a limit maximum time (Difference between throttle position and requested position is higher than 0.48%)
Case 6
  • When ETC power stage is off, Throttle cannot return by spring power in the limp-home position within a limit maximum time (Difference between Throttle position and adapted voltage in limp home position is higher than 0.18V)
Diagnostic Time
  • 0.8 to 1.2s
MIL ON Condition
  • Immediately
