DTC Information And Inspection: DTC Detecting Condition

Trouble shooting Condition Possible cause
Main action
  • Variant monitoring
  1. Faulty ESP (ESC)
  2. Variant coding is not finished.
  3. CAN Bus "OFF"
  4. Other specifications have been installed
Threshold value
  • When variant coding is not completed
  • After ignition switch is ON, if the CAN message for engine displacement, engine kind and T/M does not correspond to stored variant code in EEPROM
  • After ignition switch is ON, if there is no Optional Variant value stored in the EEPROM
Diagnosis time
  • Immediately/5 seconds
MIL
  • ESP (ESC)/ABS warning lamps are activated
Reset condition
  • When Variant coding is normally completed
