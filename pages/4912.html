DTC Information And Inspection: DTC Detecting Condition

Trouble shooting Condition Possible cause
Main action
  • Monitor the switch signal
  1. EPB switch circuit shorted
  2. Faulty EPB switch
  3. Driver's abnormal switch control (too many activation, pull or push for long time or slowly push/pull switch)
Threshold value
  • When EPB switch failure is detected due to short circuit.
MIL
  • EPB warning lamp is activated
Reset condition
  • When the EPB switch normal signal is inputted once for each Apply, Release, Neutral value in the same ignition cycle or after ignition switch turned OFF and back ON.
