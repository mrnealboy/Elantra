DTC Information And Inspection: DTC Detecting Condition

Trouble Shooting Condition Possible Cause
Main Action
  • Monitor the seat position information
  • One or more the Driver Seat Motor's Position Information* was cleared
    1. "DRIVER SLIDE MOTOR"
    2. "DRIVER FRONT HEIGHT ADJUSTER MOTOR"
    3. "DRIVER REAR HEIGHT ADJUSTER MOTOR"
    4. "DRIVER RECLINING MOTOR"
Prerequisite Condition
  • IG key "ON"
Threshold Value
  • One or more Driver Seat Motor's Position Information*: Cleared
Diagnosis Time
  • Immediately
DTC Clearing
  • Complete "Seat Limit Position Setting"
Component Name_ETM ETM
PSM* "DRIVER IMS CONTROL MODULE" SD877-2
Driver Seat Motor's Position Information* The distance that Driver Seat can be moved from front to back.
