Vehicle Shipping Mode (24-EE-012H-1)

WARNING: This page is about the Elantra N Line, Automatic DCT Trans, which is a different variant/trim than selected.
Publication date: 2024-10-01
Reference number: 24-EE-012H-1
Supersedes refnos: 20-EE-005H, 24-EE-012H

VEHICLE SHIPPING MODE

VEHICLE SHIPPING MODE

TECHNICAL SERVICE BULLETIN

Reference Number(s): 24-EE-012H-1, Date of Issue:  October 01, 2024
HYUNDAI: All Models
GROUP: ENGINE ELECTRICAL
Superceded Bulletin(s): 24-EE-012H, Date of Issue:  October 01, 2024

REVISION HISTORY

This TSB supersedes TSB # 24-EE-012H to update instrument cluster photos and add alternate procedure for vehicles equipped with CCNC/CCIC headunits. 

DESCRIPTION

Hyundai vehicles are equipped with Dark Current Control logic, also called "Shipping Mode", to help reduce amperage draw and conserve battery State of Charge (SOC) while vehicles are in transit. This feature is active when the vehicle is in the key OFF  state and will not affect vehicle functionality or performance.

This TSB outlines the procedure to change the Dark Current Control Mode using the vehicle User Setting Mode (USM) or GDS-Smart.

Hyundai highly recommends storing dealer stock vehicles in "Shipping Mode" and then setting the vehicle to "Customer Mode" when it is retailed and delivered to the customer.

Factory Mode Dealer/Shipping Mode Customer Mode (Standard Vehicle Mode)
  • Factory only
  • Displays battery SOC
  • Lowest dark current draw
  • When vehicle is shipped to dealer
  • Displays battery SOC
  • Mid-level dark current draw
  • Recommended mode for dealer stock
  • When delivered to the customer
  • Does NOT  display battery SOC
  • Retailed vehicle normal operation mode
NOTE:
  1. Displays shown are for example only. Displays will vary by model.
  2. Factory  or Dealer/Shipping Mode  automatically switches to Customer Mode  when the odometer reaches 372 miles (600 km).

Applicable Vehicles:  All models.

USER SETTING MODE (USM)

Dark Current Control Modes are set in the following order with the vehicle's User Setting Mode.

Information 

User Setting Mode does not allow going back to a previous mode from the currently selected one.

Use GDS-Smart to revert back to either Dealer Mode or Factory Mode.

GDS-SMART

Dark Current Control Modes can be accessed in any order using GDS-Smart.

SERVICE PROCEDURE

USING USM TO CHANGE DARK CURRENT CONTROL MODE

  1. To change the Dark Current Control Mode using the vehicle User Setting Mode, hold down the OK  button on the steering wheel.

The vehicle cluster will indicate the updated Dark Current Control Mode.

Information 

In Customer Mode, the battery SOC % does NOT  display in the cluster.

USING GDS-SMART TO SELECT DARK CURRENT CONTROL MODE

  1. Turn ignition ON  with the vehicle ignition key or press the Start/Stop Button to the ON  position.
  2. Connect the wireless VCI to the vehicle DLC located under the driver's side dash.
  3. Access the Hyundai GDS-Smart  tablet.
  4. Select S/W Management  .
  5. If applicable, confirm vehicle information.

    For models equipped with CCNC/CCIC headunits  , proceed to Step   9  .

    For all other models, proceed to Step 6  .
  6. Select ICU - Integrated Central Control Unit  from the System list.
  7. Select User Option  .
  8. The User Option  information table will appear.

    Select Run  to access the [Data Write] checklist.

    Proceed to Step 9  .
  9. Select PDC - Power-net Domain Control  .
  10. Select Mode Configuration  .
  11. The Mode Configuration  information table will appear.

    Select Run  to access the [Data Write] checklist.

    Proceed to Step 9  .
  12. In the [Data Write]  checklist select the Dark Current Cutoff Control  by checking the checkbox.

    Information 

    This feature is disabled if the vehicle mileage is over 372 miles (600 km).
  13. After checking the Dark Current Cutoff Control  box, an Information  message will appear.

    Select OK  .
  14. Select the applicable Dark Current Control Mode  from the drop-down list.
  15. Press OK  to set the selected Dark Current Control Mode.
  16. Upon pressing OK  , the vehicle instrument cluster will automatically shift to the selected Dark Current Control Mode.
  17. Press Cancel  on the GDS-Smart screen to complete the setting.
