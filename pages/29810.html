SERVICE GUIDE FOR USB MULTI-TERMINAL DIAGNOSIS

SERVICE GUIDE FOR USB MULTI-TERMINAL DIAGNOSIS

TECHNICAL SERVICE BULLETIN

Reference Number(s): 24-BE-006H, Date of Issue:  June 18, 2024
HYUNDAI: All Models
GROUP: BODY ELECTRICAL

DESCRIPTION

This bulletin provides information for inspection and repair of a multi-terminal that is not functioning properly. A multi-terminal enables the infotainment function by connecting an external device to the USB multi-terminal in the vehicle.

Integrated USB Multi-terminal Premium USB Multi-terminal USB-C Multi-terminal
NOTE: These are some examples of the USB Multi-terminals equipped in vehicles.

Information 

Before inspecting/repairing the multi-terminal verify that all audio components (AVN, head unit, etc.) are genuine Hyundai parts.

Applicable Vehicles: 

  • All Models equipped with a Multi-terminal (USB A-Type or C-type).
NOTE: To avoid any potential damage to IONIQ vehicles, IONIQ repairs can only be performed at IONIQ certified dealers.

WARRANTY INFORMATION

Normal warranty applies.

SERVICE PROCEDURE

Multi-terminal Connection Flowchart

INSPECTION OF COMPONENTS

  1. Confirm audio/navigation unit is a genuine Hyundai part before performing any repairs.

    Correct operation cannot be guaranteed for installation of other commercially available units due to differences in operating voltage/current, compatibility, etc.
  2. Inspect exterior of multi-terminal for damage.
    1. Broken USB pin
    2. Broken USB mounting area
    3. Foreign matter obstruction in socket

    Internal damage or breakage of the socket may be caused by excessive USB insertion, use of non-standard USB/AUX, or foreign matter obstructing the socket.

    Information 

    If damage is caused by external influence, repair cannot be claimed under warranty.

USB Drive Specifications

  1. Confirm that customer's USB drive is compatible with the USB connection in the vehicle's audio unit.

    Newer audio units use USB 3.0 technology, which is backwards compatible with USB 2.0 drives (A).

    However, if the audio unit is exclusively for USB 2.0, it may not be compatible with a USB 3.0 drive (B) when inserted.

    Refer to examples at right for photos, logos, and symbols of the two types of USB drives.
  2. Confirm a standard USB drive (C) is being used, such as the shield type shown at right.

    A non-standard USB drive (D), such as the bar type shown at right, may not function properly in an audio unit designed for USB 2.0 or 3.0.
  3. Inspect connection method of USB drive and mobile device.

    USB Hub/USB Adapter: 

    USB drives connected via a USB hub (E) or USB adapter (F) may not operate correctly.

    Smartphone Cable: 

    The vehicle's audio unit may not play music correctly through Android Auto or Apple CarPlay when connected via a smartphone cable (G).

    Additionally, if the cable is not a genuine product of the smartphone manufacturer, the smartphone recognition connection may be disconnected.

    Information 

    Non-genuine cables that are not from the phone manufacturer may not function correctly.

    Apple Inc. has an MFI (Made for iPod/iPhone/iPad) program that certifies accessories made by other companies, such as Lightning cables, to work with Apple products. These accessories should function properly.

USB Drive Function Check

  1. Check if audio is heard through vehicle's head unit after inserting USB drive.

    OK:  USB is recognized if audio/music is heard through head unit.

    NG:  Error displays on head unit if USB drive is not recognized.
  2. Inspect files on USB drive if not recognized.

    If additional files are on the drive that are not  music or audio files, then the vehicle's audio unit may not recognize the music/audio files.

    In the example at right, there are other types of files saved on the USB drive (folder, files inside folder, executable file) along with music files (mp3).
  3. Inspect the USB drive formatting method.

    OK: FAT32 

    FAT23 is the recommended file system for formatting USB drives.

    NG: NTFS 

    USB drives formatted in the NTFS system may not be recognized by the USB multi-terminal.

USB Cable Inspection

Example:  Results During Reproduction Test of Disconnection

Conclusion:  Most connection errors/disconnections were between USB cable and mobile phone during reproduction tests in a vehicle. In these cases, the multi-terminal was not defective. 

  1. When disconnection is suspected between a mobile phone and the USB multi-terminal:
    1. Check if USB cable is a genuine product sold or certified by the mobile phone manufacturer.

      Information 

      Non-genuine cables that are not from the phone manufacturer may not function correctly.

      Apple Inc. has an MFI (Made for iPod/iPhone/iPad) program that certifies accessories made by other companies, such as Lightning cables, to work with Apple products. These accessories should function properly.

    2. Check that the phone is updated to the latest operating system.

      Older OS versions may fail to connect. 

    3. Additionally, if Android Auto or Apple CarPlay repeatedly disconnects and reconnects, check that the audio/AVN software in the vehicle is updated to the latest version.

      Information 

      Phone connection errors/disconnections display as a "connected to car" message on the phone, but an "unavailable" message displays in the vehicle.

  2. Check condition of USB cable. If it is damaged or bent, it may not function properly to transfer data to the multi-terminal.

    See example at right of a damaged cable.
  3. Inspect the length of the cable used to connect to the multi-terminal. A cable around 1 m (approx. 3.28 ft) long is recommended.

    Information 

    Testing results showed that the longer the cable length, the higher the rate of recognition failures and disconnections occurred.

  4. Confirm that the cable being used is not a charging cable, such as the 3-in-1 cable shown at right. These cables should only be used for charging a mobile device. They are not functional for transferring data.

Final Inspection Before Multi-terminal Replacement

If all previous inspections were completed successfully and the multi-terminal is suspected to be defective, inspect the items below before  replacing the multi-terminal.

  1. First, remove the crash pad and any necessary components to access the connectors and cables for the multi-terminal.

    Information 

    Follow procedures in the applicable Shop Manual.

  2. Verify that the connector (A) is firmly connected.
    • If not firmly connected, pull it out and reconnect it, then test the USB multi-terminal functions again. If all functions are normal, no further action is required.

    Information 

    There have been cases where the connector was not connected or connected poorly during installation of a taxi meter.
    • If connector was firmly connected, go to the next step.
  3. Inspect the rear connector pins (B).
    • If no issues are found, go to the next step.
  4. Check condition of connector cable.
    • Check if cable is damaged (C).
    • Check if cable is excessively bent (D). If cable is bent beyond repair and cannot be used, replace the cable.
    • If no issues are found, go to the next step.
  5. Inspect the head unit connector (E) and connection of the multi-terminal cable.
    • Check for loose connection of the multi-terminal cable. If connection is loose, this can cause disconnection issues in the USB/C-type ports.

      Reconnect it securely and verify all connected audio functions are normal.
    • If connector is damaged as shown in example at right, head unit replacement is recommended.
  6. If no issues were found in steps  1 -  5, then replace the multi-terminal.
  7. Verify proper operation of all infotainment functions using the multi-terminal connections.
