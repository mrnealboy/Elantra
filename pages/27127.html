DTC Information And Inspection: DTC Detecting Condition

Trouble Shooting Condition Possible Cause
DTC Strategy
  • CAN Communication Monitoring
  1. UART Communication error
  2. Open/short in temperature sensor
  3. Open/short in charging coil
Enable Condition
  • ACC "ON"
  • Normal Battery Voltage
Threshold Value
  • Not initialized communication or Checksum mismatch between the MCU and the Charging Controller
  • The voltage of temperature sensor lower than 0.2V or higher than 4.8V
  • Charging coil current is abnormal

    * If any one of the above case occur, it is determined as failure
DTC Detecting Time
  • Charging controller error: 1000 ms
  • Temperature sensor error: 150 ms
  • Transmitting coil error: 150 ms
Recovery Time
  • When fault cleared
