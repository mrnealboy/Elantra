Monitor Current Data

WARNING: This page is about a different variant/trim than selected.
  1. Connect GDS to Data Link Connector (DLC).
  2. Ignition "On"
  3. Select and monitor from Current Data:
    1. Shift Lever Switch
    2. Sports Mode Select
    3. Sports Mode Switch "Up"
    4. Sports Mode Switch "Down"
    5. Current Gear
  4. Test Drive vehicle and monitor Middle Speed Sensor Data
