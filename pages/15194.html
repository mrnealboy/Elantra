Pcm (ECM/TCM)

Courtesy of HYUNDAI MOTOR AMERICA

ECM monitors errors through checksum. Every information consists of the combination of 0 and 1, checksum means summing up all values in a row. Thus, errors are recognized comparing checksum value and the memory value at ECM.
