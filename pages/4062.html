Repair Procedures: Inspection

  1. Remove the memory power seat connector
    Courtesy of HYUNDAI MOTOR AMERICA
  2. When each switch is pressed, check the electricity flow between memory power seat switch connector and grounding, and if the electricity does not match the specification, replace the switch.
