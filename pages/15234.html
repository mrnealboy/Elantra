DTC Information And Inspection: DTC Detecting Condition

Trouble Shooting Condition Possible Cause
Main Action
  • Monitor the voltage of switch terminal
  1. Faulty steering angle sensor
  2. Zero-point calibration error
Prerequisite Condition
  • Turn on the ignition switch and start the engine
Threshold Value
  • The column turns by more than 680° from point 0
  • The motor position sensor has a fault
Diagnosis Time
  • 2 sec
