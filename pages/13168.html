Repair Procedures: Reassembly

  1. Install the insulator, spring seat, coil spring and dust cover from the strut.
  2. The spring (A) is compressed using a spring compressor until there is some tension in the spring.
    Courtesy of HYUNDAI MOTOR AMERICA
  3. Install the self locking nut from the strut by using the SST (09546-3X100).
    NOTE:
    • Do not reuse the self locking nut.

    Tightening torque:  98.0 - 107.8 N.m (10.0 - 11.0 kgf.m, 72.3 - 79.6 lb-ft)

    Courtesy of HYUNDAI MOTOR AMERICA
