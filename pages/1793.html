Component (Location) And Function: Cluster: Function

The cluster module controls a variety of functions installed on a control panel including MIL, trip computer, cluster text warning display, USM*, and sounds by receiving information through CAN communication lines. It also functions the variant coding, which synchronizes the cluster settings with the vehicle's system specifications transmitted by GDS.

DTCs will set when the vehicle information from CAN BUS and that from EOL* do not correspond. On the assembly line, EOL communication will terminate if any DTC is not detected through DTC search. At the service field, the cluster setting must be completed through variant coding using GDS in order to synchronize the vehicle information on GDS with that on the cluster.
