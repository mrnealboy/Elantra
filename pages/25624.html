DTC Description

U01B000 is set when Battery Monitor Module* cannot transmit "BATTERY SENSOR"'s information to the ECM* or it transmits a invalid information to the ECM*.

When this fault is detected, check the communication status between the "BATTERY SENSOR" and the Battery Monitor Module*, then check the Battery Monitor Module*.
