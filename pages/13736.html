Monitor Current Data

  1. Connect a GDS to DLC (Data Link Cable).
  2. Start the engine and warm it up to the normal operation temperature.
  3. Check the items related to an "VSS" on "Current Data" using the GDS. (ENG. Control)
  4. Check the items related to an "WHEEL SPEED SENSOR" on "Current Data" using the GDS. (ESC Control)
