DTC Setting Condition

Trouble Shooting Condition Possible Cause
Main Action
  • Monitor the ACU CAN signals
  1. Open/short in CAN communication circuit
  2. ACU module (SRS Control Module)
Prerequisite Condition
  • 2 sec. after turning the ignition switch on
  • Voltage is within normal range (9~16V)
  • Engine is running or Being assumed it is running
  • Not ESC CAN TIMEOUT
  • BCA status is not OFF
Threshold Value
  • ACU CAN message is not transmitted
Diagnostic Time
  • After 1 sec.
