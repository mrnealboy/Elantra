DTC Setting Condition

Trouble Shooting Condition Possible Cause
Main Action
  • Monitor the data coming from the EMS
  1. Faulty EMS*
  2. Faulty IMMOBILIZER*
Threshold Value
  • During the authentication process, which is a part of its communication, the VIN from the EMS is different from the one registered with the IMMOBILIZER*.
Diagnostic Time
  • 500 ms
DTC Clearing
  • Clear the DTC using GDS
NOTE: IMMOBILIZER*: "IBU"
EMS*: "ECM"/"PCM"
