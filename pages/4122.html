Power Seat Module: Function

PSM* controls the position adjustment of Driver Seat by the manual seat switch or IMS*. And it is connected to ICU* to form B-CAN network of the vehicle.

Component Name_ETM Description ETM
PSM* "DRIVER IMS CONTROL MODULE" Power Seat Module SD877-2
ICU* CGW SJB
  • "ICU JUNCTION BLOCK"
  • "ICU JUNCTION BLOCK IPS CONTROL MODULE"
  • "ICU JUNCTION BLOCK"
  • [CGW+SJB] Integrated Central control Unit
  • Central GateWay
  • Smart Junction Block
IMS* Integrated Memory System
