In-car Temperature Sensor

Courtesy of HYUNDAI MOTOR AMERICA

The in-car temperature sensor is linked to the heater and A/C control module. It contains a thermistor and transmits the variable resistance value to the A/C module according to the in-car temperature. Then the A/C module controls the interior temperature in line with the signal.
