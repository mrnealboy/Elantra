DTC Setting Condition

Trouble Shooting Condition Possible Cause
Main Action
  • Monitor the FCA module variant coding
  1. Error in specifications
  2. Error in vehicle assembly
  3. Variant coding was not conducted
Prerequisite Condition
  • Battery Voltage is between 9V and 16V
  • Ignition has been on for over 2 seconds (Time Delay)
  • CAN communication lines are normal
Threshold Value
  • Variant coding is not completed or Variant coding does not correspond to vehicle data

Case 1) Variant coding is not conducted
Case 2) When a CAN message is received from the LKA after a setting where FCA does not apply
Diagnostic Time
  • Immediately
MIL
  • FCA/SCC operation cancelled/inhibited
  • FCA/SCC warning lamp ON
