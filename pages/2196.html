DTC Setting Condition

Trouble Shooting Condition Possible Cause
Main Action
  • Monitor the TCU*'s CAN message reception
  1. Oepn in CAN high/low line
  2. Faulty CAN line
  3. TCU*
Prerequisite Condition
  • Turn the ignition switch ON
Threshold Value
  • The ADAS-PRK* unit has not received a message from the TCU*
Diagnosis Time
  • An invalid CAN message has been detected for 0.5 sec
DTC Clearing
  • -
NOTE: ADAS-PRK*: "Advanced driver assistance system - Parking"
TCU*: "Transmission Control Unit"
