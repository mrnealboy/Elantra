Repair Procedures: Installation

  1. Install the power window switch assembly.
  2. Install the front door trim after connect the connector.
  3. Connect the negative (-) battery terminal.
    NOTE:
    • Make sure that the switch connectors are plugged in properly.
    • Check the power door mirror system for normal operation.
