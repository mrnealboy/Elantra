Warning Lamp Activation

The airbag system control module detects the presence or absence of an airbag system when power is supplied and turns on the airbag warning lamp.

  1. When the airbag system is normal

    When the airbag system is normal, the airbag warning light turns on for 6 seconds and then goes out.

    Courtesy of HYUNDAI MOTOR AMERICA
  2. When the airbag system is broken

    If there is something wrong with the airbag system, it lights up for 6 seconds, then turns off for 1 second and then lights up continuously.

    Courtesy of HYUNDAI MOTOR AMERICA
  3. When turning the ignition switch ON during variant coding (EOL) mode, the airbag warning lamp is turned on and blinks at intervals of 1 second till the coding is completed.

    In case the variant coding is normally completed, the airbag warning lamp is turned on for 6 seconds, and then turned off. Otherwise the airbag warning lamp continuously blinks at intervals of 1 second.

    1. In case the variant coding is normally completed
      Courtesy of HYUNDAI MOTOR AMERICA
    2. In case the variant coding is not completed.
    Courtesy of HYUNDAI MOTOR AMERICA

    When there is active fault in airbag system or SRSCM internal fault, the variant coding (EOL) cannot be completed. In this case, perform the variant coding (EOL) procedure again after troubleshooting with the diagnostic tool.

    In the following cases, the airbag warning light continues to light.

    • Current airbag system failure or internal airbag system control module failure
    • If there is a collision fault code
    • When communicating with the airbag system control module using a diagnostic tool

    In the event of a malfunction in which the airbag system control module fails to operate, the airbag warning lamp operation cannot be properly controlled. In this case, the airbag warning lamp operates normally through a circuit that operates independently of the airbag system control module.

    • Loss of battery supply to the SRSCM: airbag warning lamp turned on continuously.
    • Loss of internal operating voltage: airbag warning lamp turned on continuously.
    • Loss of work airbag system control module: airbag warning lamp turned on continuously.
    • When the airbag system control module is not connected
