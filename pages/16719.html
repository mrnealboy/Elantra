Smart Key Code Saving

  1. Connect the DLC cable of Diagnostic tool to the data link connector (16 pins) in driver side crash pad lower panel, turn the power on Diagnostic tool.
    Courtesy of HYUNDAI MOTOR AMERICA
  2. Select the 'S/W Management' and 'Car model'.
    Courtesy of HYUNDAI MOTOR AMERICA
  3. Select the 'Smart Key Unit' and 'Smart Key Code Saving'.
    Courtesy of HYUNDAI MOTOR AMERICA
  4. Follow the instructions on the screen.
    Courtesy of HYUNDAI MOTOR AMERICA
