DTC Information And Inspection: DTC Detecting Condition

Trouble shooting Condition Possible cause
Main action
  • Monitor the CAN message from MDPS
  1. Poor connector connection
  2. Short circuit between CAN bus lines.
  3. Defective wire
  4. Faulty MDPS
  5. MDPS incorrectly occupy the CAN Bus line
  6. Incorrect Controller's version
Threshold value
  • A failure is detected when MDPS message's counter fault is received for more than specific time.
  • A failure is detected when MDPS message's checksum value fault is received for more than specific time.
  • A failure is detected when MDPS message's steering torque sensor fault or column torque fault is received for more than specific time.
  • A failure is detected when MDPS defective fault message is received for more than specific time.
Diagnosis time
  • While controlling: 500 milliseconds
  • While not controlling: 1500 milliseconds
MIL
  • No MIL On
Reset condition
  • When the normal state is confirmed after ignition switch turned OFF and back ON.
