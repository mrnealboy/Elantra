Evaporator Sensor

Courtesy of HYUNDAI MOTOR AMERICA

The evaporator sensor is installed in the heater unit and measures the temperature of the heater core to prevent any damage to the component caused by overcooling. The sensor contains a thermistor that transmits the variable resistance values to the A/C module according to the temperature. Then the A/C module cuts off power supply to the compressor relay when the values from the sensor are below a specified level.
