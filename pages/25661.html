DTC Information And Inspection: DTC Detecting Condition

Trouble Shooting Condition Possible Cause
Main Action
  • Monitor signals
  1. Poor contact of connector
  2. Continuous Variable Valve Duration (CVVD)
Prerequisite Condition
  • Enable of Stored Adaptation Data Diagnosis
  • No Communication faults present
  • CVVD Motor Control Enable
Threshold Value Case 1
  • Maximum learning value is not within specification or the learning value from position sensor is greater than threshold value
Case 2
  • Minimum learning value is not within specification or the learning value from position sensor is lower than threshold value
Case 3
  • Counter of Position sensor abnormal change is higher than 2 count
Case 4
  • Adaptation time is higher than 10 sec
Diagnostic Time
  • Immediate
MIL
  • 1st Driving Cycle
