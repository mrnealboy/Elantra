Inspection AATS

  1. Turn ignition switch OFF and connect GDS.
  2. Turn ignition switch ON.
  3. Select "Diagnostic Trouble Codes (DTC)," and click "DTC Status" to check DTC information.
  4. Read the "DTC State" parameter.
  5. Record all DTCs, DTC state and freeze frame data before clearing them. Is the DTC State "Present?"

Code rational, ECU Calculates Ambient Air Temperature utilizing Intake Air Temp Sensor (IAT) and Engine Coolant Temperature (ECT) Sensor, this calculated value is compared to the actual value supplied via CAN from the A/C Control Module. If the difference is 77°F (25°F) or greater the code will set.

Check for items affecting CAN Communication or for an abnormality in Ambient Air Temperature Sensor (AATS) circuit/reading. If abnormality noted utilize the following Body Codes within Air Conditioning DTC Guide to diagnose:

  • B1237 Ambient Temperature Sensor Short (Low)
  • B1238 Ambient Temperature Sensor Short (High)
