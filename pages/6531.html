Repair Procedures: Reassembly

NOTE:
  • Thoroughly clean all parts to be assembled.
  • Before installing the parts, apply fresh engine oil to all sliding and rotating surface.
  • Always use new valve stem seals.
  1. Install the valves.
    1. After applying engine oil to the valve stem seal, install a new valve stem seal using the special tool (09222-2B100).
      NOTE:
      • Do not reuse old valve stem oil seals.
      • Incorrect installation of the seal could result in oil leakage past the valve guides.
      • Do not reassembly ones in the other's places.
      CAUTION:
      • Intake valve stem seals are different from exhaust ones in type.
    2. Install the spring seats.
    3. Apply engine oil to the entire outer surface of each valve stem and insert the valve inside the valve guide.
    4. Install the valve spring.
    5. Install the retainer.
    6. Using the SST (09222-3K000, 09222-3K100), compress the valve spring and install the valve spring retainer lock.
