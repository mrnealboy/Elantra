DTC Description

The Supplemental Restraint System Control Module (SRSCM) sets DTC B138200 if the measured resistance value of the Passenger Side airbag (PSAB) circuit is more than the threshold value.

*In this case, the SRSCM checks if there's any fault in circuit by sending current for a while.
