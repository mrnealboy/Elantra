Monitor DTC Status

  1. Connect GDS to Data Link Connector (DLC).
  2. Turn the ignition switch ON.
  3. Select "Diagnostic Trouble Codes (DTC)" and click "DTC Status" to check DTC information.
  4. Read the "DTC State" parameter.
  5. Is the DTC "Present"?

    Present 

    • Diagnose the IEB system using the GDS and see if there is a DTC related to the IEB. If so, repair it first and then see if the DTC is cleared from the BCW module. Then, go to next procedure.

    History 

    • The memory was not cleared after repair. Clear the DTC and go to "Verification of Vehicle Repair".
