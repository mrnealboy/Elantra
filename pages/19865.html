Monitor Current Data

  1. Connect GDS to Data Link Connector (DLC).
  2. Diagnose the engine.
  3. Check if there is any DTC related to the SPEED Sensor, inspect this first. Then, see if the DTC is cleared.
  4. If no relevant DTC exist, select the "SPEED Sensor" parameter on the "Current data" of the GDS.
  5. Check whether the vehicle speed changes as changing the vehicle speed.
