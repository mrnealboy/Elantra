Roof Crossbar Installation (23-BD-010H)

WARNING: This page is about the Elantra N Line, Automatic DCT Trans, which is a different variant/trim than selected.
Publication date: 2023-06-06
Reference number: 23-BD-010H

ROOF CROSSBAR INSTALLATION

ROOF CROSSBAR INSTALLATION

TECHNICAL SERVICE BULLETIN

Reference Number(s): 23-BD-010H, Date of Issue:  June 01, 2023
HYUNDAI: All Models
GROUP: BODY

DESCRIPTION

This bulletin provides general guidelines for roof crossbar installation. On certain Hyundai models, the roof crossbars are available for purchase as an accessory. It is critical to follow installation procedure to ensure safe operation and proper location setting of the crossbar in fore-aft direction to minimize wind noise related complaints.

To minimize wind noise, always install the roof crossbar at the location indicated and follow the step-by-step roof crossbar installation instructions for each model. 

Applicable Vehicles:  All Hyundai vehicles equipped with Genuine Hyundai Roof Crossbars.

Warranty Information: 

NOTE: 1: Normal warranty applies.
NOTE: 2: Any repairs due to improper installation of the roof crossbars are not warrantable.

SERVICE PROCEDURE

Information 

To access the installation guide, go to the Hyundai Tech Info (HTI) or Hyundai Accessories site. Select the correct installation guide equipped with or without a sunroof or panoramic roof. 

Go to Hyundai Tech Info (HTI) at https://www.hyundaitechinfo.com  :

Go to Hyundai Accessories at https://www.hyundaiaccessories.com  :

Information 

Roof crossbar installation: 

  • Read the entire installation guide for the applicable model prior to installation
  • Clean the roof rail molding s before installation.
  • Install the crossbars with the proper orientation facing forward.
  • Make sure to install the front crossbar ONLY  at the specified location (per the applicable installation guide, and do NOT  install the crossbars beyond the indicated location towards the front to minimize wind noise.
