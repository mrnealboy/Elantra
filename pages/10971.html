Monitor Current Data

  1. Connect GDS to Data Link Connector (DLC).
  2. Turn the ignition switch ON and warm up the vehicle up to an operational temperature.
  3. Select "Engine Coolant temperature sensor" parameter on the "Current Data" of the GDS.
  4. Check whether the value of the sensor changes according to the engine temperature change.
