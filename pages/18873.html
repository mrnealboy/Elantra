Turbine Speed Sensor

WARNING: This page is about a different variant/trim than selected.
  1. Output Shaft Speed Sensor 

    Turbine speed sensor: a sensor for detecting the internal speed of the IVT (Intelligent Variable Transmission) Sensor. Driving pulley speed sensor: a sensor for detecting the internal driving pulley rotational speed of the IVT. Output shaft speed sensor: a sensor for detecting the IVT output shaft speed.
