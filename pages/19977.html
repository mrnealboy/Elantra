Monitor Current Data

  1. Plug GDS to Data Link Connector (DLC).
  2. Start the engine.
  3. Select "PDW Active" on "Current Data".
  4. Monitor if the value changes while turning the "PDW (Parking Distance Warning) switch" on and off.
