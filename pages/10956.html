Monitor Current Data

  1. Connect GDS to Data Link Connector (DLC).
  2. Diagnose the engine ECM.
  3. Check if there is any DTC related to the A/C pressure sensor, inspect this first. Then, see if the DTC is cleared.
  4. If no relevant DTC exist, select the "air conditioner pressure sensor" parameter on the "Current data" of the GDS.
  5. Check whether the value of the APT sensor changes as turning the A/C switch ON and OFF.
