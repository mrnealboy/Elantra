DTC Information And Inspection: DTC Detecting Condition

Trouble shooting Condition Possible cause
Main action
  • Internal monitoring
  1. Faulty EPB system
  2. Faulty EPB Software
Threshold value
  • When the mismatch between the EPB motor driver and the PBC command lasts for more than 500 milliseconds
  • When undefined values of PCB motor driver state and power supply state are input for more than 500 milliseconds to ESP
  • When PCB function call does not occur more than 1 second
  • When an undefined signal is input from the communication interface between HOST and PCB
  • When one or more of the functions of the EPB software are not performed, or the order of execution is changed and maintained for more than 200 milliseconds
Diagnosis time
  • 500 milliseconds/200 milliseconds
MIL
  • EPB/AVH warning lamps are activated
Reset condition
  • Turn ignition switch OFF and ON
