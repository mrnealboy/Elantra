DTC Description

C164C87 is set when BCW ECU (Rear-RH) can not read BSD ECU (Rear-LH) information through CAN line.

* If three of the left local CAN DTC set simultaneously:

Check wiring connector which is inside of lower front left bumper (Driver's seat)

BSD DTC: C164A87 No front Left local CAN signal,

C164B87 No front Right local CAN signal,

C164C87 No rear Left local CAN signal
