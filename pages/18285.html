DTC Description

B102055 is set when the variant coding encrypts that the vehicle does not have TPMS* although it does.

Cluster* will determine the state of each module through CAN BUS. When the modules do not correspond the variant coding information, a DTC will set.

When this DTC appears, perform the "S/W Management" → "CLU Variant Coding" and arrange the vehicle's system specification settings. The DTC will be cleared when the programming completes properly.
