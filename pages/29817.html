DESCRIPTION

This bulletin describes operation of the "Cadex Rapid RC Battery Tester" for preventive maintenance battery check, and for repair work on 12-volt batteries. This tester can conduct a complete battery health check of all service drive vehicles to confirm "Good Battery", or a "Replace Battery" result. It can help improve customer satisfaction to avoid potential negative experience of jump start or no start. The tester has a rapid test time of 15 seconds. A complete test including input entry, save, and printout takes about 1.2 minutes.

The Rapid RC Tester uses a cutting edge patented 24-frequency "Electrochemical Impedance Spectroscopy" (EIS) scan to completely check battery health including all of the following conditions:

Battery Condition Definition Unit Comments
RC  Reserve Capacity Rated mins. Measured RC is indicated as Good/Poor 
CCA (SAE)  Cold Cranking Amps Amps Be sure to enter CCA (SAE)  rating, not (EN)
Resistance High  Battery internal plate/connection/weld deterioration restricting battery current supply
SOC  State of Charge % 0-100% full charged.
OCV  Open Circuit Voltage Volts  

Applicable Vehicles:  All models

SERVICE PROCEDURE

The Rapid RC Battery Tester's unique EIS technology operates from an internal rechargeable Li-ion battery. The tester should be charged daily while not in use. The tester can check up to 300 vehicles on a fully charged internal battery. It can show results for every battery including dead batteries at very low voltage.

The Rapid RC Battery Tester should be used only for non-warrantable activities  . The tester can rapidly decide Good Battery  versus Replace Battery  depending on state of charge (SOC  ) levels as per below:

Testing a Battery:

  1. Connect the Battery Tester clamps to the vehicle's battery, making sure that the black clamp is connected to the battery negative "-" terminal and the red cable's clamp is connected to the battery positive "+" terminal. The Tester will warn if connected backwards.
    NOTE: Make sure vehicle ignition, interior and exterior lights are OFF  for battery testing.
    CAUTION: When testing the battery, connect the battery tester to the battery terminal's metal or battery post firmly, not to the securing nuts. Otherwise, the test result displayed on the battery tester will be incorrect. See examples below of "Good" and "Bad" connections.
    GOOD Connection BAD Connection
    CAUTION: In some vehicles such as the Tucson Plug-in and Santa Fe Hybrid, the battery is located in the trunk and there is an extension terminal located in the engine compartment. In this case, DO NOT  test battery using the extension terminal in the front. Always connect the tester directly to the battery. Otherwise, the result will not be correct.
  2. Turn the Rapid RC Tester power ON  and follow these screen by screen instructions.

    The example detailed below is for a Customer Used Vehicle with a Replace Battery result.

    1. Select Test Battery,  and then press OK.
    2. Using select Test Type  *, and then press OK  .
      NOTE: * Only select Customer Used Veh  .
      Do NOT  select PDI/Stock/New Veh  .
      Refer to TSB # 24-EE-003H  , Battery App Phase 2, for warrantable claims.
    3. Use keys to select battery Chemistry  , and then press OK  .
      NOTE: Refer to these examples. If you are not sure which, then refer to the battery application chart on the last page of this TSB.

      Information 

      Refer to page 4  of this TSB for Battery Type explanation.
    4. For a Customer Used Veh  test type you will enter the RC  rating from the battery label, and then press OK  .
      NOTE:
      • You must  enter a valid RC  rating in the Customer Used Veh  test type to assure a proper test result.
    5. Enter the CCA (SAE)  rating from the battery label, and then press OK  .
      NOTE:
      • You must  enter a valid CCA (SAE)  rating to ensure a proper test result.
      • Be sure to select the correct value of CCA (SAE)  ; not the (EN) value.
    6. Enter the last 6 numeric digits of the VIN then press OK  :
    7. Testing will proceed for approximately 15 seconds.
    8. The Result screen will appear like the example shown. Press OK  to save it in the tester memory.
    9. The battery test result data is saved in the tester memory.
      NOTE:
      • Up to the last 150 test results are saved in the Tester's memory.
      • Refer to the Cadex User Manual,  pages 23-27, for instructions on how to access saved data.
    10. Press the OK  button to print the battery test result, or use the buttons to select No  before pressing the OK  button.
    11. The tester (or device) will produce a printout if Yes  was selected at the Print Receipt screen in the previous step.
  3. Follow the flowchart below as a procedure guideline.
