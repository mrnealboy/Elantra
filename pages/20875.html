Inspection AATS

WARNING: This page is about a different variant/trim than selected.
  1. Ignition "OFF"
  2. Connect GDS to Data Link Connector (DLC).
  3. Engine "ON".
  4. Monitor following parameters in "Current Data" with GDS.
    Courtesy of HYUNDAI MOTOR AMERICA

    Check for abnormality in the Ambient Air Temperature Sensor (AATS) reading. If abnormality noted utilize the following Body Codes within Air Conditioning DTC Guide to diagnose:

    • B123711 Ambient Temperature Sensor Short (Low)
    • B123813 Ambient Temperature Sensor Short (High)
