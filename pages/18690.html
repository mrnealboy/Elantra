High Speed CAN Network

WARNING: This page is about a different variant/trim than selected.
Courtesy of HYUNDAI MOTOR AMERICA

High Speed CAN Network is a BUS structure that consists of CAN High and CAN Low line. The CAN lines compose one main line and many branch lines. The ends of the main line's CAN High and Low line are connected with a terminal resistor. Branch lines that are attached to the Main line serves as a bridge among control modules.

CAN Communication is optimized for transmitting data between modules.

  • P-CAN system that controls the engine and transmission
  • C-CAN system that administers safety control of brake, SRS, etc.

Communication error DTCs will set when one of the two High Speed CAN lines suffers an open or circuit faults.
