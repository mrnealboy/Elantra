Monitor Current Data

WARNING: This page is about a different variant/trim than selected.
  1. Connect GDS to Data Link Connector (DLC).
  2. Engine "On"/Test Drive.
  3. Select "Current Data" Mode and monitor the following:
    1. Damper Clutch Slip
    2. Engine RPM
    3. Input Speed (PG-A)
    4. Torque Convertor Clutch Control State
    5. Torque Convertor Clutch Control Solenoid Valve

      Specification:  When Torque Convertor Clutch Control State is "On", "Damper Clutch Slip" will be less than 100 RPMs.
