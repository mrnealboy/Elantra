Monitor Current Data

  1. Plug GDS to Data Link Connector (DLC).
  2. Start the engine.
  3. Select "PDW Active" and "PDW Indicator Voltage" on "Current Data".
  4. Monitor if the value changes while turning the "PDW (Parking distance warning)" on and off.
