REVISION HISTORY

This TSB supersedes 25-01-024H to update the Applicable Vehicles section and add "Verification of Bluelink Enrollment Status" on page 2 to check enrollment status using VIN Search on Hyundai Tech Info. 

Dealers must perform this service campaign on all affected vehicles prior to customer retail delivery and whenever an affected vehicle is in the shop for any maintenance or repair.

Access the "Vehicle Information" screen via WebDCS to identify open campaigns.

DESCRIPTION

Some vehicles may exhibit a loss of connectivity or interruptions in the middle of using Bluelink Service functions. This may be due to an irregular disconnection on Verizon's communication network. Follow the procedure in this TSB to reestablish the connection via the AVN pinhole reset method.

SERVICE PROCEDURE

VERIFICATION OF BLUELINK ENROLLMENT STATUS

  1. On Hyundai Tech Info select VIN Search  (A).
  2. Enter VIN in the VIN Search  field and select Search  (B).
  3. Check the Bluelink Enrollment Status  (C).
    • If status is ACTIVE  - Perform both the AVN Pinhole Reset  and Verification of Connection  procedures.
    • If status is anything other than ACTIVE  - Perform the reset ONLY.  Go to AVN Pinhole Reset  below.

AVN PINHOLE RESET

  1. Turn ON  the ignition (A).
  2. Insert a pin or equivalent object into the small hole (B) for approximately 2 seconds. 

    Information 

    Be sure to press the button inside the hole to reset the AVN system. Screen will go black and reset.

  3. ONLY  for vehicles with "ACTIVE"  Bluellink enrollment status:

    Proceed to Verification of Connection. 

VERIFICATION OF CONNECTION (VEHICLES WITH "ACTIVE" BLUELINK ENROLLMENT STATUS ONLY)

  1. Select Bluelink  (A).
  2. Select Bluelink Settings  (B).
  3. Select Activate  (C) or Reconfigure  (D) to activate Bluelink.

    Information 

    A loading screen will appear while Bluelink activation is in progress.
  4. Verify Bluelink activation success: Select OK  (E) if Bluelink is activated.

    Information 

    If Bluelink does NOT  show activated, please contact Techline.

  5. The service procedure is complete.
