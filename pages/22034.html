Monitor Current Data

WARNING: This page is about a different variant/trim than selected.
  1. Connect GDS to Data Link Connector (DLC).
  2. Engine "ON"
  3. Select "Current Data" Mode and monitor the following:
    1. Shift Control Solenoid Valve (46/C)
    2. Current Gear
    3. Next Gear Position
    4. Sport Mode Select
    5. Engine RPM

    Specification  : Current reading increases as Solenoid activated
