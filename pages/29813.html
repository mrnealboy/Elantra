HYUNDAI OVER-THE-AIR (OTA) SOFTWARE UPDATE INTRODUCTION AND CUSTOMER COMMUNICATION INFORMATION

HYUNDAI OVER-THE-AIR (OTA) SOFTWARE UPDATE INTRODUCTION AND CUSTOMER COMMUNICATION INFORMATION

TECHNICAL SERVICE BULLETIN

Reference Number(s): 23-GI-012H, Date of Issue:  December 27, 2023
HYUNDAI: Any OTA Capable Models
GROUP: GENERAL INFORMATION

DESCRIPTION

This bulletin outlines the processes for Over-The-Air (OTA) software updates and the customer notification channels associated with these updates.

Hyundai customers may receive electronic notifications via text, email, Bluelink phone application, or message via vehicle screen regarding OTA updates. An active Bluelink subscription is required and customers should enable OTA software update notifications.

Applicable Vehicles: 

Any OTA capable models (active with Bluelink).

I. What are Over-The-Air (OTA) Software Updates? 

Over-the-Air (OTA) software update are wireless communication to deliver the latest software directly to the vehicle. OTA software updates enable the vehicle to become better equipped over time, providing essential safety, performance, and feature enhancements efficiently and securely.

As an update becomes available, the software can be deployed over the air and downloaded while driving. OTA updates will be released in parallel with the diagnostic tools. This means, if a vehicle with an open campaign arrives at the dealership before the software was installed by a customer, the dealership can perform the update using the regular authorized diagnostic tool currently used.

Once the vehicle is parked and IGN OFF with the driver's door closed, additional details will be shown to approve and start the update, or delay until later (refer to item 3 on step II). Any delayed updates can easily be reinitiated through the infotainment screen when it's convenient.

Once the update has started, it will continue the installation automatically in the background. Progress may be checked on the infotainment screen by turning accessory mode ON (refer to item 4 on step II).

The Bluelink app will notify when the vehicle is refreshed and ready to go (refer to step V for examples). The next time the vehicle is turned on, a message will be displayed on the infotainment screen confirming installation along with a QR code to learn more.

NOTE:
  • Vehicle cannot be driven during an update.
  • Vehicle charging and Vehicle to Load (V2L) functionality are unavailable when an update is in progress and can resume once complete.
  • Over-the-Air (OTA) software updates are only available for active Bluelink Service vehicles.
  1. Download S/W 

    Software update download will begin in the background automatically. There is no notification or icon shown to inform the download's status, but a download progress may be checked in the Software Information screen. Notification will be given once download is completed.
  2. IGN OFF 

    Update remains on standby until the ignition is turned off. Ignition OFF will trigger the 'Update Start' popup to prompt customers to start installation.
  3. Update Start Popup 

    Update ready popup notification will be shown after ignition OFF. Popup message will provide options to start the update, postpone it, or view more details.
  4. Update in progress 

    After update is started, system will check that the preconditions are satisfied to proceed with the installation, the update will proceed in the background once these preconditions are confirmed.

    Preconditions  : Vehicle Off, Gear in P (Park), Parking brake ON, Exterior lights Off, Engine hood Closed, and vehicle not charging.
  5. Update complete 

    After a successful OTA software update, the system will reboot and display "What's New" message on the display of the head unit.

    This message provides confirmation of a successful OTA software update.

III. How is the download progress of an OTA software update displayed on the Head Unit? 

  1. Download for the OTA Software update will commence in the background without displaying a notification.
    NOTE: Hold "Setup" button to directly access this page.

    For download status, go to "SW Info/Update" information screen under General Settings. 

  2. Once the software update is downloaded, the status will show "Preparing to install the update. Ready to update."

    System is checking the integrity of the download and making the final preparations for the update.
  3. After the system confirms the download and checks the integrity of the update, status will show "The update can be started after the vehicle is turned OFF."

    Car can continue to be driven and update will not commence until vehicle is turned OFF.

    IV. How is a download update installed by an owner? 

  4. After vehicle is turned OFF, update popup is shown displaying several options:
    • [Install Now] - Update will start.
    • [Details] - Additional details for the update can be reviewed.
    • [Later] - Update will be postponed until next IGN OFF.

    Details page will show additional information regarding the OTA update.

    The vehicle owner will still have the option to start or postpone the update.

  5. Once [Install Now] is selected, the system will check that the preconditions are met prior to starting the installation.

    There is a 60 second time-out which can be skipped by selecting [Update Now].
  6. The update will start and continue running on the background even if the screen is turned OFF.
  7. Update progress can be checked by turning vehicle's Accessory Mode ON.
    NOTE:
    1. Accessory Mode can be turned ON by pressing on the Start button without stepping on the BRAKE pedal.
    2. Door should remain closed for the screen to remain ON to check progress.
  8. Upon a successful installation,

    "What's New" popup will be shown on the head unit.

    Update details can be reviewed by selecting [Details] or by scanning the QR code with a mobile phone.

V. Customer Communications and OTA Software Update Portals: 

  • For recalls and campaigns, a pre-notification email may be delivered to the customer electronically. Pre-notification email will provide introductory information on an upcoming OTA software update along with general requirements.
  • Status updates during the OTA software update process may be sent to the customer via text message, Bluelink app push notifications, and/or email dependent on the selected notification preferences.

VI. Diagnostics: OTA Software Update Events and History 

OTA Software update events and history can be viewed on the following two portals:

  1. WebDCS 
    • Input VIN number to search.
    • Scroll down to sections:
      • Over The Air Software Update Not Performed
      • Over the Air Software Update History
  2. Hyundai Tech Information 
    • Select VIN search and input VIN number.
    • Scroll down to section:
      • OTA Software Update - Current And Target Software
