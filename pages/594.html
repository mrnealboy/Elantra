DTC Description

P168800 is set when an incorrect PIN code or password was entered more than 3 consecutive times while the IGN1 remains On.

NOTE:
  1. During key registration, the IMMO sets the DTC when a wrong PIN code which does not match with the previously registered one has been input more than 3 consecutive times.
  2. During initialization, the IMMO sets the DTC when a wrong PIN code which does not match with the previously registered one has been input more than 3 consecutive times.
  3. During password modification, the IMMO sets the DTC when a wrong password which does not match with the previously registered one has been input more than 3 consecutive times.
  4. During the Limp Home mode, the IMMO sets the DTC when a wrong password which does not match with the previously registered one has been input more than 3 consecutive times.
