DTC Description

C161F64 is set when the EPS ECU (MDPS=Motor Driving Power Steering Control Module) has received an abnormal vehicle speed signal.

* The steering wheel would get suddenly less heavy when it receives the speed signal at 0 Kph due to engine vehicle speed error while driving. To prevent this, the system detects the vehicle speed on the cluster and the default mode in the engine, and then it controls the vehicle at default speed at 80 Kph.
