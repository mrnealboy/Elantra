Repair Procedures: Installation

  1. Connect the audio unit connectors and cable.
  2. Install the audio head unit.
  3. Install the cluster fascia panel.
  4. Install the cluster fascia side panel.
  5. Install the cluster fascia upper garnish.
  6. Install the photo sensor cover.
  7. Connect the negative (-) battery terminal.
    NOTE:
    • Make sure the connector are connected in properly.
    • Check the audio system.
